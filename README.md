# Data Science Projects
Projects in Data Science and Machine Learning

## Projects Overview

### 1. Climate Change Model
Analysis of climate change data using NASA datasets to identify trends and patterns in global temperature changes.

### 2. Covid-19 Data Science Project
Comprehensive analysis of COVID-19 clinical trials data to extract insights and trends during the pandemic.

### 3. Customer Satisfaction Prediction
Machine learning model to predict customer satisfaction based on support ticket data. Includes trained model (best_model.pkl).

### 4. Google Play Store Analysis
Data analysis of Google Play Store apps and user reviews to understand app performance and user sentiment.

### 5. Netflix Analysis
Exploratory data analysis of Netflix content to uncover patterns in content distribution, genres, and trends.

### 6. OCD Patient Dataset
Analysis of Obsessive-Compulsive Disorder patient data to identify patterns and insights for healthcare research.

### 7. Tobacco Use and Mortality
Comprehensive analysis of tobacco use impact on mortality rates using multiple datasets including admissions, fatalities, and prescriptions.

## Repository Structure
Each project contains:
- Jupyter notebook with analysis
- Dataset(s) in CSV format
- requirements.txt for dependencies
- 1ntro.md with project introduction

## Getting Started
Navigate to any project folder and install dependencies:
```bash
pip install -r requirements.txt
```
